# 3. 마이페이지

## 3-1. 프로필 조회 / 수정

- 수정 가능 항목
    - 이름
    - 성별
    - 닉네임

## 3-2. 내 모임 목록

- 리스트 view

## 3-3. 알림 페이지

- GNB 우측에 읽지 않은 알림이 있다고 아이콘 표시
- 알림 목록 조회시 읽지 않은 알림은 읽음 으로 처리
- 새로운 일정 알림

- 새로운 챌린지 알림
    - 챌린지를 생성한 본인을 제외한 모든 모임 멤버에게 알림
- 일정 수정 / 취소 알림 (추후)
- 일정 시작 전 Reminder (추후)

# 4. 모임 목록 페이지

- 모임 목록 조회
    - 공개된 모임만 조회
    - 기간 제한 없이 생성일 기준 최신순으로 조회
- 검색
    - 키워드 검색 대상 : 모임명, 소개, 지역
    - 카테고리 필터
    - 지역 필터 - 추후에 지역코드를 입력하면 구현하기로

# 5. 모임 생성 페이지

- 필드
    - 모임명
    - 지역 (필수)
        - 지금은 text
        - 온라인 모임은 `온라인` 입력
        - 추후에 : 동까지 선택 → 구까지 표현 / 온라인
    - 소개
    - 이미지 (선택)
        - 입력하지 않으면 기본 이미지 사용
    - 최대 인원
        - 사용자가 직접 입력
        - 최대 300명까지 입력 가능
    - 카테고리 : 드롭다운
    - 공개 여부 및 가입 방식
        1. 공개 모임
            - 모임 목록에 노출
            - 로그인한 회원은 모임 홈 조회 가능
            - `가입하기` 버튼을 누르면 승인 절차 없이 즉시 가입
        2. 비공개 모임
            - 모임 목록에 노출하지 않음
            - 초대 URL로만 가입
            - 딥링크 공유 - 난독화

# 6. 모임 상세 페이지

## 모임 상세 메뉴

- 홈
- 챌린지
- 일정
- 가계부
- 채팅

---

## 6-1. 모임 홈 페이지

- 모임 상세 정보
- 공개 모임에 가입하지 않은 로그인 회원
    - 모임 홈만 조회 가능
    - 챌린지, 일정, 가계부, 채팅 메뉴는 표시하지 않음
    - `가입하기` 버튼 표시
    - 인원이 가득 찬 모임은 '가입하기' 버튼을 비활성화 처리 후 가입 마감으로 텍스트 수정
- 모임장 / 일반 멤버 권한 구분
    - 모임장
        - 모임 수정
        - 모임 삭제 (추후)
    - 일반멤버
        - 탈퇴 버튼
- 비공개 모임 멤버
    - `모임에 초대` 버튼 표시
    - 버튼을 누르면 모임 ID를 노출하지 않는 초대 URL을 복사하고 버튼 아래에 표시
    - 초대 URL은 버튼을 누르기 전에는 표시하지 않음
- 멤버 목록

---

## 6-2. 모임 챌린지 페이지

- 조회 : 리스트 뷰
- 챌린지 생성 : 모든 모임 멤버 가능
- 챌린지 수정 / 삭제 : 해당 챌린지 작성자만 가능
    - 모임장도 다른 멤버가 작성한 챌린지는 수정하거나 삭제할 수 없음
- 모임 챌린지 생성 필드
    - 제목
    - 설명
    - 이미지 사용 여부 : 챌린지 인증 시 이미지 필수 여부를 정하는 체크박스
        - 챌린지 대표 이미지를 의미하지 않음
    - 기간 : 시작일과 종료일
        - 시간은 입력하지 않고 날짜만 입력
        - 시작일과 종료일 당일을 모두 챌린지 기간에 포함
- 인증 목록 조회 : 이미지 필수 여부에 따라 리스트 View 다름
    - 이미지 필수 : 갤러리 뷰
    - 이미지 없는 경우 : 리스트 뷰

---

## 6-3. 모임 일정 페이지 ⭐️

- momo에 저장된 일정을 Calendar 형태로 조회
- Google Calendar API는 사용하지 않음
- 일정 생성 : 모든 모임 멤버 가능
- 일정 수정 / 삭제 : 해당 일정 작성자만 가능
- 작성자는 일정 생성시 scheduleMembers 컬렉션에 추가
- 모임 일정 생성 필드
    - 제목
    - 설명
    - 날짜 (시작일 / 종료일)
        - 시간은 입력하지 않고 날짜만 입력
    - 장소
    - 반복 (추후)

- 모임 일정 상세 페이지
	 - 참여 여부
        - 각 멤버가 자신의 참여 여부를 선택
        - 해당 버튼을 누르면 일정 scheduleMembers 컬렉션에 추가됨.

---

## 6-4. 모임 가계부 페이지 ⭐️

- momo에 저장된 가계부 내역을 Calendar 형태로 조회(추후)
- Google Calendar API는 사용하지 않음(추후)
- 가계부 내역 생성 : 모든 모임 멤버 가능
- 가계부 내역 수정 / 삭제 : 해당 내역 작성자만 가능
- 가계부 생성 필드
    - 타입 (수입 / 지출)
        - 수입은 세부 유형으로 구분하지 않음
    - 내역
    - 금액
    - 날짜
	    - 달력에서 선택
    - 메모
- 합계
- 영수증 OCR 첨부 (추후)
    - 영수증의 금액인지
    - 금액이면 무조건 가져오지 않게
    - 적절한 이미지가 아닌 것은 에러 처리 추가
